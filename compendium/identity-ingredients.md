# Identity Ingredients — Small Purchases That Unlock Whole Cuisines

Use this when the question is:

> **What one jar / paste / spice should I buy if I want several new meals to become possible?**

This is the opposite of buying twenty obscure ingredients for one recipe.

The project wants **high-leverage identity ingredients**: products that survive in the pantry/fridge/freezer and make boring chicken/rice/tofu/fish taste like a different destination.

# The purchasing rule

Before buying a specialty ingredient, ask:

1. **Does it unlock at least two plausible meals?**
2. **Does it last long enough that there is no pressure to use it immediately?**
3. **Does it remove annoying work or create a flavour that ordinary pantry ingredients cannot?**

If yes, it is a strong compendium ingredient.

The project should happily own twenty powerful jars/spices if those twenty jars turn a boring grocery backbone into fifty different dinners.

The pantry is allowed to be interesting so the nightly cooking can stay simple.
