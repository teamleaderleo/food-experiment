# Recipes by Workflow

Use this when the question is **“How much hand-work do I feel like doing?”**

The project’s strongest cooking preference is not absolute speed. It is **low attention density**: food can take a while if hands and brain are mostly free.

See also [`../experiments/002p-phone-compatible-cooking.md`](../experiments/002p-phone-compatible-cooking.md).

# Workflow lesson

The project’s default recipe shape is becoming:

> **5–10 minutes simple setup → long mostly-unattended window → one or two interventions → eat now + useful leftovers.**

That gives far more culinary range than trying to make every meal literally quick.
