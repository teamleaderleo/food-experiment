# Source-selection rule

When several recipes exist for the same dish, prefer sources that give at least one of these:

- a method that clearly reduces hand-fuss
- credible cultural/home-cooking context
- useful substitution notes
- strong storage/reheating guidance
- clear photos/video that make technique obvious

The repository should record **our easiest successful version**, not blindly preserve every step in the source recipe.
